Drop any royalty-free or licensed .mp3, .wav, or .m4a music tracks into this folder.
When running `gscc-highlights`, every track placed here automatically appears in the music picker.

You can also pass any external file path directly:
  uv run gscc-highlights prepare --youtube <URL> --ncca <URL> --music "/path/to/song.mp3"

Or skip background music (great if you want to attach trending audio inside Instagram):
  --music none
